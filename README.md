**项目名称：基于 Amazon Video Games 数据集的生成式推荐系统研究与实践**

本项目基于 Amazon Video Games 真实用户交互数据，围绕传统序列推荐与生成式推荐技术，独立完成了从数据预处理、特征表示、模型训练到推荐生成及效果评估的完整流程。项目涵盖约2.56万件商品，首先使用 SASRec 构建传统序列推荐基线，再利用预训练文本模型提取商品语义向量，通过 RQ-VAE（残差量化变分自编码器）将连续语义表示转换为离散 Semantic ID（语义标识符）。在此基础上，实现 TIGER 生成式推荐模型，基于 Transformer Encoder–Decoder 架构自回归生成商品 Semantic ID，并结合 Beam Search（束搜索）与 Trie（前缀树）约束解码，生成合法的 Top-K 商品推荐列表。同时，探索 HSTU 序列建模方法，以及基于 Qwen2.5-0.5B 和 LoRA（低秩适配）的轻量化大模型生成式推荐方案。最终，通过 Recall@10、NDCG@10 等指标对模型进行评估与比较，其中 SASRec 的 Recall@10 达到 0.0795，TIGER 达到 0.0741。本项目重点实践了商品语义离散化、用户行为序列建模、自回归生成和推荐系统离线评估等关键技术，加深了对传统推荐向生成式推荐演进路径的理解。
